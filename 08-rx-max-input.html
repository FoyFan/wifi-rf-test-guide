08 接收机最大输入电平08 Receiver maximum input level

在规定误包率下仍能正常接收的最强信号电平——保证近距离强信号下接收机不饱和、不掉线。

The strongest input level still received at the required PER — ensures the front end does not saturate at close range.

测试目的 / Purpose

  • 信号太强会导致接收机前端（LNA/混频器）饱和、大信号压缩，解调失败——表现为“手机贴着 AP 反而掉线”。
  • 主要在 DV 阶段验证；产线一般不测（需要反向灌大信号，工装不方便）。
  • Too-strong signals saturate the LNA/mixer and break demodulation — the classic “phone next to the AP disconnects” case.
  • Verified at DV stage; production lines usually skip it (reverse high-level injection is awkward).

测试步骤 / Procedure

  1. 信号源发强信号直接灌入 DUT——不需要衰减器，必要时近距离耦合或加放大。
  2. 典型从 0 dBm 开始，发 1000 包统计 PER。
  3. 在标准规定的最大电平区间内（如 −30 dBm 到 0 dBm，具体看代际）逐点验证。
  4. Inject a strong signal directly into the DUT — no attenuator; close coupling or extra gain if needed.
  5. Start at 0 dBm, send 1000 packets, count PER.
  6. Verify every level in the standard's high-level range (e.g. −30 to 0 dBm, generation-dependent).

判定标准 / Pass criteria

  • 在规定最大电平（802.11 通常要求到 0 dBm）下 PER ≤ 10%。
  • At the specified maximum level (802.11 typically requires up to 0 dBm), PER ≤ 10%.

超标表现 / If it fails

  • 接收机前端饱和/压缩 → 解调失败。改不了软件，通常是前端设计余量不足，需硬件评估。
  • Front-end saturation/compression breaks demodulation. Not fixable in software — usually a front-end design margin issue needing hardware review.

标准依据 / Standard basis

  • 接收机最大输入电平定义于 802.11-2016 Clause 17.3.10.3（OFDM，Receiver maximum input level：在 −30 dBm 至 0 dBm 范围内 PER ≤ 10%）；HT Clause 20.3.10.3；VHT 沿用同类要求（Clause 21.3.6，Receiver maximum input level）。11ax 在 802.11-2024 Clause 27 中扩展。
  • 标准要求接收机在 −30 dBm 到 0 dBm 全区间保持 PER ≤ 10%，上限通常为 0 dBm。
  • RX maximum input level: 802.11-2016 Clause 17.3.10.3 (OFDM, Receiver maximum input level: PER ≤ 10% from −30 dBm to 0 dBm); HT Clause 20.3.10.3; VHT keeps the equivalent requirement (Clause 21.3.6). 11ax extends it in Clause 27 of 802.11-2024.
  • The standard requires PER ≤ 10% across the whole −30 to 0 dBm range, with a ceiling of typically 0 dBm.

标准依据：IEEE Std 802.11-2016（合并了 OFDM/HT/VHT 各 PHY 的条款编号， Clause 17/20/21）；802.11-2016 已被 802.11-2020 取代，2020 又被 802.11-2024 取代，条款编号一致。法规项另见 FCC Part 15.247/15.407 与 ETSI EN 300 328/301 893。

Standard basis: IEEE Std 802.11-2016 (consolidated clause numbering for the OFDM/HT/VHT PHYs, Clauses 17/20/21); 802.11-2016 was superseded by 802.11-2020, itself superseded by 802.11-2024, with identical clause numbering. Regulatory items: FCC Part 15.247/15.407 and ETSI EN 300 328/301 893.
