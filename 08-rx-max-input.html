08 接收机最大输入电平08 Receiver maximum input level

在规定误包率下仍能正常接收的最强信号电平——保证近距离强信号下接收机不饱和、不掉线。

The strongest input level still received at the required PER — ensures the front end does not saturate at close range.

测试目的 / Purpose

  • 信号太强会导致接收机前端（LNA/混频器）饱和、大信号压缩，解调失败——表现为“手机贴着 AP 反而掉线”。
  • 主要在 DV 阶段验证；产线一般不测（需要反向灌大信号，工装不方便）。
  • Too-strong signals saturate the LNA/mixer and break demodulation — the classic “phone next to the AP disconnects” case.
  • Verified at DV stage; production lines usually skip it (reverse high-level injection is awkward).

测试步骤 / Procedure

  1. 信号源发强信号直接灌入 DUT——不需要衰减器，必要时近距离耦合或加放大。
  2. 典型从 0 dBm 开始，发 1000 包统计 PER。
  3. 在标准规定的最大电平区间内（如 −30 dBm 到 0 dBm，具体看代际）逐点验证。
  4. Inject a strong signal directly into the DUT — no attenuator; close coupling or extra gain if needed.
  5. Start at 0 dBm, send 1000 packets, count PER.
  6. Verify every level in the standard's high-level range (e.g. −30 to 0 dBm, generation-dependent).

判定标准 / Pass criteria

  • 在规定最大电平（802.11 通常要求到 0 dBm）下 PER ≤ 10%。
  • At the specified maximum level (802.11 typically requires up to 0 dBm), PER ≤ 10%.

超标表现 / If it fails

  • 接收机前端饱和/压缩 → 解调失败。改不了软件，通常是前端设计余量不足，需硬件评估。
  • Front-end saturation/compression breaks demodulation. Not fixable in software — usually a front-end design margin issue needing hardware review.
