03 调制精度 EVM03 Transmit modulation accuracy (EVM)

衡量调制波形“准不准”——实际星座点与理想星座点的偏差，直接决定最高可用调制速率。

How accurate the modulated waveform is — the deviation of actual constellation points from ideal. It caps the top usable MCS.

测试目的 / Purpose

  • EVM 太大时对端解调不出数据，直接限制最高速率（256QAM/1024QAM 对 EVM 要求更苛刻）。
  • 这是最能暴露射频链路问题（相位噪声、IQ 不平衡、PA 压缩）的测试。
  • High EVM breaks demodulation and caps the top rate; 256QAM/1024QAM demand tight EVM.
  • The most revealing test for phase noise, IQ imbalance and PA compression.

测试步骤 / Procedure

  1. DUT 发最高阶调制的满速率包（11ax MCS11 = 1024QAM；11ac 的 256QAM）——EVM 只在最高阶调制下才暴露问题。
  2. 综合仪/VSA 解调，对每个 OFDM 符号的每个子载波计算：EVM(dB) = 20·log₁₀(误差矢量幅值 / 理想幅值)。
  3. 测 100~1000 个包取统计。
  4. 报告：平均 EVM、最差子载波 EVM、最差符号 EVM、EVM 随时间/子载波分布图。
  5. DUT transmits full-rate packets at the highest-order modulation (11ax MCS11 = 1024QAM; 256QAM for 11ac) — EVM problems only show there.
  6. Demodulate with the VSA; per subcarrier and symbol compute EVM(dB) = 20·log₁₀(|error| / |ideal|).
  7. Collect 100–1000 bursts for statistics.
  8. Report mean EVM, worst subcarrier, worst symbol, and EVM vs time/subcarrier plots.

判定标准 / Pass criteria

调制 ModulationEVM 限值 Limit
QPSK≤ −10 dB (35%)
16QAM≤ −16 dB (16%)
64QAM≤ −25 dB (5.6%)
256QAM≤ −30 dB (3.2%)
1024QAM (11ax MCS10/11)≤ −35 dB (1.8%)

结果分析 / Analysis

  • 只有边缘子载波 EVM 差 → 频偏/相位噪声问题。
  • 符号首尾 EVM 差 → IQ 不平衡或时域漂移。
  • 整体 EVM 差 → PA 压缩或功率过高，先降功率再看。
  • Only edge subcarriers bad → frequency offset / phase noise.
  • First/last symbols bad → IQ imbalance or timing drift.
  • Uniformly bad → PA compression or over-power; lower power and retry.

常见坑 / Pitfalls

  • 只看平均 EVM → 边缘子载波/偶发符号劣化测不出来，实际用网会掉速率。
  • 用低阶调制测 EVM → 永远 pass，但毫无信息量。
  • Mean-only EVM hides edge-subcarrier or sporadic degradation; real networks will drop rate.
  • Testing EVM at low-order modulation always passes and tells you nothing.
