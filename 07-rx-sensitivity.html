07 接收机最小输入灵敏度07 Receiver minimum input sensitivity

在规定误包率下能正常解调的最弱信号电平——数值越低（越负）代表“耳朵越灵”、覆盖越好。

The weakest input level the receiver can demodulate at a required PER — the lower (more negative), the better.

测试目的 / Purpose

  • 直接决定弱信号下的覆盖能力与掉线表现。
  • 这是 WFA 认证的 RX 核心项，产线常抽测。
  • Determines coverage and disconnect behavior at weak signal.
  • Core RX item for WFA certification; often sampled on the production line.

测试方向（重要） / Direction (important)

与 TX 项方向相反：仪器当发射端，DUT 当接收端。仪器发已知信号，DUT 报收包统计。Opposite direction from TX tests: the instrument transmits, the DUT receives and reports its receive statistics.

测试步骤 / Procedure

  1. 建立回环：DUT 收到包后通过测试模式回传收包计数给仪器。
  2. 信号源发标准参考包：固定速率（参考速率：如 11b 1 Mbps、11n MCS0）、固定包长（OFDM 4096 字节 / DSSS 1024 字节）、共 1000 包。
  3. 从较强电平开始，逐步衰减（步进 1 dB）降低 DUT 输入电平。
  4. 每个电平统计误包率（PER），找到 PER 恰好达到 10% 的电平点。
  5. 补偿：该电平 − 线损 = DUT 天线口实际输入电平 = 实测灵敏度。
  6. Establish the loop: the DUT reports its received-packet count back via test mode.
  7. Send the standard reference packet: fixed rate (e.g. 11b 1 Mbps, 11n MCS0), fixed length (4096-byte OFDM / 1024-byte DSSS), 1000 packets.
  8. Step attenuation (1 dB) to lower the DUT's input level from a strong start.
  9. Count PER at each level; find the level where PER first reaches 10%.
  10. Compensate: that level − cable loss = the actual level at the DUT antenna port = measured sensitivity.

判定标准 / Pass criteria

  • 实测灵敏度 ≤ 标准限值（更好或相等）。例如：11n 20MHz MCS0 限值 −82 dBm；11ac MCS9 80MHz 限值 −72 dBm。
  • 灵敏度裕量测试：在“限值 +3 dB”的电平下 PER 仍 ≤ 10%。
  • Measured sensitivity ≤ the standard limit (equal or better). E.g. 11n 20 MHz MCS0 limit −82 dBm; 11ac MCS9 80 MHz limit −72 dBm.
  • Sensitivity margin test: at limit + 3 dB, PER must still be ≤ 10%.

常见坑 / Pitfalls

  • 屏蔽箱不干净、线缆屏蔽不良 → 环境信号污染结果，灵敏度虚差。测之前先测噪底。
  • DUT 没关省电/没锁速率 → PER 被重传和速率切换污染。
  • Leaky shield box or cables → ambient signals pollute the result; measure the noise floor first.
  • DUT not in fixed-rate / power-save disabled → PER polluted by retries and rate switching.
