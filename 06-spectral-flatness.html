06 频谱平坦度 Spectral flatness06 Transmit spectral flatness

整个信道带宽内各子载波功率应基本一致——频谱“高低不平”会让部分子载波传的数据出错。

Subcarrier power across the channel should be flat; ripple corrupts data on the weak subcarriers.

测试目的 / Purpose

  • 发现滤波器滚降、频偏、信道估计等问题。
  • 平坦度差 → 部分子载波 SNR 低 → 高阶调制时这些子载波必然出错。
  • Reveals filter roll-off, frequency offset and channel-estimation issues.
  • Poor flatness → low SNR subcarriers → guaranteed errors at high MCS.

测试步骤 / Procedure

  1. DUT 发满带宽调制包（80 MHz 带宽发满 234 个数据子载波）。
  2. 仪器解调，测每个子载波功率，画带内功率曲线。
  3. 与平均功率比，检查各子载波起伏是否在标准窗内。
  4. DUT transmits full-bandwidth packets (234 data subcarriers at 80 MHz).
  5. Demodulate and plot per-subcarrier power.
  6. Check ripple against the standard's window, relative to the mean.

判定标准 / Pass criteria

  • 802.11 规定：中心 ±16 个子载波内起伏 ≤ +1/−2 dB；边缘子载波 ≤ +2/−4 dB。
  • 全部子载波都必须落在窗内。
  • IEEE 802.11: within the center ±16 subcarriers, ripple ≤ +1/−2 dB; edge subcarriers ≤ +2/−4 dB.
  • Every subcarrier must fall inside the window.

超标分析 / If it fails

  • 曲线整体倾斜 → 频偏过大或滤波器滚降。
  • 中间凹陷 → 时钟同步/信道估计问题。
  • 局部尖峰 → 滤波器/匹配网络谐振。
  • Overall tilt → excessive frequency offset or filter roll-off.
  • Mid-band dip → clock sync / channel-estimation issue.
  • Local spikes → filter or matching-network resonance.

标准依据 / Standard basis

  • 频谱平坦度定义于 802.11-2016 Clause 17.3.9.7（OFDM，Transmit spectral flatness）；VHT Clause 21.3.9.7（按 20/40/80/160 MHz 带宽分别给出分组窗）；HT 参照 Clause 20.3.9.4 对平坦度的要求。±16 子载波内 ≤ +1/−2 dB、边缘 ≤ +2/−4 dB 即 Clause 17 的分组窗。
  • Spectral flatness: 802.11-2016 Clause 17.3.9.7 (OFDM, Transmit spectral flatness); VHT Clause 21.3.9.7 (per-bandwidth grouping windows for 20/40/80/160 MHz); HT per Clause 20.3.9.4. The ±16-subcarrier center window ≤ +1/−2 dB and edge ≤ +2/−4 dB come from Clause 17's grouping.

标准依据：IEEE Std 802.11-2016（合并了 OFDM/HT/VHT 各 PHY 的条款编号， Clause 17/20/21）；802.11-2016 已被 802.11-2020 取代，2020 又被 802.11-2024 取代，条款编号一致。法规项另见 FCC Part 15.247/15.407 与 ETSI EN 300 328/301 893。

Standard basis: IEEE Std 802.11-2016 (consolidated clause numbering for the OFDM/HT/VHT PHYs, Clauses 17/20/21); 802.11-2016 was superseded by 802.11-2020, itself superseded by 802.11-2024, with identical clause numbering. Regulatory items: FCC Part 15.247/15.407 and ETSI EN 300 328/301 893.
