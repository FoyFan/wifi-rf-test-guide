04 发射频率误差 Frequency error04 Transmit frequency error

测载波实际频率与标称频率的偏差（ppm），主要反映晶振精度与 AFC 校准质量。

Carrier offset from the nominal frequency in ppm; reflects crystal accuracy and AFC calibration.

测试目的 / Purpose

  • 频偏过大时接收端可能无法锁定/解调，尤其在高阶调制和长帧下。
  • 频偏主要来源是晶振（±20 ppm 级别），靠产线 AFC 校准补偿。
  • Large offset prevents the receiver from locking/demodulating, especially at high MCS and long frames.
  • Mainly from the crystal (±20 ppm class); compensated by production AFC calibration.

测试步骤 / Procedure

  1. DUT 发正常调制包（不用连续波——解调法估的是残余频偏）。
  2. 仪器解调后估计载波频偏，报 ppm = (频偏 / 载波频率) × 10⁶。
  3. 多信道都测：锁相环在不同频点表现可能不同。
  4. 温度敏感：严谨场景在高低温下复测。
  5. DUT sends normal modulated packets (demodulation estimates residual offset).
  6. Report ppm = (offset / carrier frequency) × 10⁶.
  7. Test several channels — PLL behavior varies by frequency.
  8. Temperature-sensitive: re-test at temperature extremes for rigorous runs.

判定标准 / Pass criteria

  • ≤ ±20 ppm（802.11 标准值）。
  • 产线常用 ±10 ppm 作为校准通过判据。
  • ≤ ±20 ppm per IEEE 802.11.
  • Production lines often gate at ±10 ppm.

超标处理 / If it fails

  • 产线做 AFC（自动频率校准）写入校准数据后复测。
  • 若 AFC 后仍超标，查晶振规格或晶体负载电容匹配。
  • Run AFC on the line, write calibration data, re-test.
  • If still failing, check the crystal spec and load-capacitor matching.
