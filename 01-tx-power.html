01 发射功率 Transmit power01 Transmit power

测量设备发射信号的最大强度（dBm）。功率过高会违规/干扰他人，过低则覆盖不足。

Measure the DUT's transmit level in dBm. Too high violates regulations; too low kills coverage.

测试目的 / Purpose

  • 验证各信道/速率/天线口的发射功率在规格范围内，且各信道间差异（功率平坦度）达标。
  • 这是法规认证（FCC/CE/SRRC）的强制项，也是产线校准的核心项。
  • Verify TX power per channel/rate/antenna is within spec, and inter-channel flatness is acceptable.
  • Mandatory for regulatory certification (FCC/CE/SRRC) and a core production-line item.

环境搭建 / Setup

  1. DUT 放入屏蔽箱，RF 口通过线缆/耦合器接到综合测试仪（或频谱仪）。
  2. 校线损：用网分或功率计测出线缆在各频点（2.412/2.437/2.472 GHz、5.18/5.5/5.8 GHz…）的损耗，输入测试软件补偿。
  3. 用芯片厂工具（wlu / art2 / MP tool）让 DUT 进入测试模式，脱离协议栈。
  4. Put the DUT in a shield box; connect its RF port to the combo tester (or spectrum analyzer) via cable/coupler.
  5. Calibrate cable loss at each working frequency and compensate in software.
  6. Use the vendor tool (wlu / art2 / MP tool) to enter test mode.

测试步骤 / Procedure

  1. DUT 设为连续发射（Continuous TX）或发满速率包流，固定信道/速率/带宽。
  2. 仪器测信道内平均功率（多个包取平均），检波用 RMS/Average。
  3. 遍历每个信道、每档速率、每根天线（如 2.4G 的 1/6/11 信道 × 11b/g/n 各速率）。
  4. 补偿：DUT 实际功率 = 仪器读数 + 线损。
  5. Set continuous TX or a full-rate packet stream; fix channel/rate/bandwidth.
  6. Measure in-channel average power (average over many bursts, RMS/average detector).
  7. Sweep every channel, rate and antenna (e.g. 2.4G ch 1/6/11 × 11b/g/n rates).
  8. Compensate: actual DUT power = instrument reading + cable loss.

判定标准 / Pass criteria

  • 功率在规格范围内：法规限值（如 FCC 2.4G ≤ +30 dBm EIRP）以内，产品规格通常定 18~23 dBm。
  • 信道间功率差异通常 ≤ 1.5~2 dB，否则说明校准表有问题。
  • Power within spec: below the regulatory limit (e.g. FCC 2.4G ≤ +30 dBm EIRP); product specs typically 18–23 dBm.
  • Inter-channel delta typically ≤ 1.5–2 dB, otherwise the calibration table is suspect.

常见坑 / Pitfalls

  • 不校线损 → 功率虚高/虚低，全表失真。
  • 频谱仪用峰值检波 vs 综合仪用平均检波，读数会打架——统一按标准配置。
  • Skipping cable-loss calibration corrupts every number.
  • Peak vs average detector makes instruments disagree — follow the standard's configuration.

标准依据 / Standard basis

  • 发射功率本身在 802.11-2016 中无统一上限（17.3.9.1 仅规范发射功率的标注与控制），上限由各国法规定：美国 FCC Part 15.247（2.4G ≤ +30 dBm EIRP / 1W）、15.407（5G U-NII）；欧洲 ETSI EN 300 328 / EN 301 893（5G ≤ 23 dBm EIRP）；中国 SRRC。
  • 信道间平坦度/功率控制精度参考 17.3.9.1（Transmit power）与 17.3.9.2 的要求。
  • 802.11-2016 itself sets no unified TX-power ceiling (17.3.9.1 covers power annotation and control); limits come from national regulation: FCC Part 15.247 (2.4G ≤ +30 dBm EIRP / 1 W), 15.407 (5G U-NII); ETSI EN 300 328 / EN 301 893 (5G ≤ 23 dBm EIRP); China SRRC.
  • Inter-channel flatness / power-control accuracy per 17.3.9.1 (Transmit power) and 17.3.9.2.

标准依据：IEEE Std 802.11-2016（合并了 OFDM/HT/VHT 各 PHY 的条款编号， Clause 17/20/21）；802.11-2016 已被 802.11-2020 取代，2020 又被 802.11-2024 取代，条款编号一致。法规项另见 FCC Part 15.247/15.407 与 ETSI EN 300 328/301 893。

Standard basis: IEEE Std 802.11-2016 (consolidated clause numbering for the OFDM/HT/VHT PHYs, Clauses 17/20/21); 802.11-2016 was superseded by 802.11-2020, itself superseded by 802.11-2024, with identical clause numbering. Regulatory items: FCC Part 15.247/15.407 and ETSI EN 300 328/301 893.
